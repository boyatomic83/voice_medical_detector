SPEC vs REALITY: CONFLICTS / THINGS TO KNOW
---------------------------------------------------------
1. Dataset slug not set. Most "Parkinson" datasets on Kaggle are TABULAR (the UCI
   Oxford CSV with 195 rows, e.g. debasisdotcom/parkinson-disease-detection). Those
   have NO audio and NO usable speaker ID, so they can't be used with this spec.
   A good fit that has raw .wav files AND one folder per speaker:
     ieeeai/italian-parkinsons-voice-and-speech   (Italian PVS, Dimauro et al.)
     classes: Young Healthy Control / Elderly Healthy Control / People with PD,
     tasks: vowels (V*), sentences/words (B*, D*, FB*), reading passage (PR*).
2. Repo name: SPEC says "voice-disease-detection", your GitHub repo is
   boyatomic83/voice_medical_detector. The notebook will clone THAT URL.
   The repo must be PUBLIC so Kaggle can git clone it (or the notebook breaks).
3. Your .env has KAGGLE_TOKEN (new-style API token), not KAGGLE_USERNAME/KAGGLE_KEY.
   Kaggle CLI 2.x reads it as KAGGLE_API_TOKEN. To use the CLI yourself:
       set -a; . ./.env; set +a; export KAGGLE_API_TOKEN="$KAGGLE_TOKEN"
   Auth works (I tested with `kaggle datasets list`).
4. Codespace has Python 3.14; Kaggle uses ~3.11/3.12. That's why requirements.txt
   uses version ranges instead of exact == pins: exact pins wouldn't install on both.
5. .env is now in .gitignore. NEVER `git add -f .env`.

M4: DONE  (WavLM / Whisper embeddings with caching)
---------------------------------------------------------
Created:
  src/features_ssl.py   microsoft/wavlm-base-plus (default) + openai/whisper-base encoder.
                        Mean-pool of a configurable hidden layer (default last) over
                        valid (non-padded) frames; clips >30 s chunked and chunk vectors
                        averaged; torch.no_grad(); GPU if available.
                        Cache: embeddings_<model>.npy + embeddings_<model>_index.csv
                        (only missing recordings are extracted; a model/layer change
                        invalidates the cache).
                        Batching: batch_size 8 on GPU (length-sorted, attention mask),
                        cpu_batch_size 1 on CPU (batching 30 s clips got the process
                        killed at 7 GB RAM in this Codespace).
  tests/test_ssl.py     cache, chunk averaging, bad-file skip, layer invalidation
                        (fake encoder, so no model download in tests)
